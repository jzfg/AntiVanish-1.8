# AntiVanish Module (Forge 1.8.9, cliente)
Tecla J: lista de staff (anadir/quitar). Se guarda en .minecraft/config/antivanish_staff.json.
Avisos: staff desaparece del tab sin mensaje de salida (posible vanish), en espectador, o invisible cerca.
Build: GitHub Actions (JDK 8 + Gradle 2.14.1 + ForgeGradle 2.1). El jar sale reofuscado en build/libs.
Limite: si el plugin de vanish deja al jugador en el tab, no se puede detectar desde el cliente.
